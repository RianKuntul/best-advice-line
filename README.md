(`u-pangg7-the-best-advice-i-ever-got-358cefb0`, $2 pot split over the top 10).

`main.ts` (Node 22, no dependencies) writes one original sentence about the
best advice the writer ever received to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). The line is a fixed string
in the source: deterministic, no network, no randomness, no trailing newline.

Run it:

```sh
node main.ts
```
